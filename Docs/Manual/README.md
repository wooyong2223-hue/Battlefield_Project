## 현재 요약

- 입력·상태·표시·설정·풀의 책임 분리가 존재한다. 보병 조준 보정과 발사 컨트롤러, 로컬 Editor 연결은 추가 분리 검토 대상이다.
- 자체 소스179개를 목록화하고 주요 흐름을 검토했다. 전체 소스의 모든 실행 경로를 검사한 결과는 아니다.
- 최신 주요 PlayMode43개 중39개 통과,4개 실패. 권총 단발 전환을 테스트 입력에 반영하는 작업이 남았다.
- 보병 HUD는 무기·탄약·발사모드·HP를 표시한다. 수류탄·자세·다운·부활·교체대 안내는 현재 제거된 상태다.
- 소총은 B로 모드 전환, X로 거치, V로 시점 전환. 수류탄 모션은 OFF, 실제 투척/궤적 기능은 코드에 구현돼 있다.

## 상태를 읽는 방법

기능 목록의 항목은 코드 구현 존재를 뜻한다. 씬에 연결됨, Play 시 생성됨, 비활성 설정, 실행 테스트 통과 여부를 각 문서에서 구분한다. `개선 후보`는 요구와 비용을 검토할 설계 선택이다. `검증 실패`는 실제 테스트 결과다. 과거 작업 문서의 통과 기록은 현재 결과와 별도 취급한다.

## 직접 구현할 때

1. 기능 목록에서 담당 코드를 찾는다.
2. SceneAndInput에서 실제 오브젝트·에셋과 현재 설정을 확인한다.
3. Architecture에서 상태 소유자와 호출 방향을 확인한다.
4. 한 기능을 수정하고 Validation의 관련 경로를 확인한다.

상세 색인의 프리팹 인스턴스 표시는 원본 프리팹과 실제 Hierarchy를 함께 확인한다.
