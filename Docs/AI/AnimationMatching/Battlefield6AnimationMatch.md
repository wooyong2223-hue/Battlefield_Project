# Battlefield 6 보병 동작 — 보유 Quaternius 선정표

2026-10-29. 범위: 저장한 UAL 1·2 Standard에서 사용할 원본 클립을 선택한다. 이번 작업은 선정 기록이며 Animator·코드·씬·프리팹·애니메이션·설정값을 교체하거나 연결하지 않았다.

## 확인 기준

- 저장본은 UAL1 43개 + UAL2 43개 원본 항목(각 팩 A_TPose 포함). 일반/RM 두 변형으로 172개 에셋이다. 두 팩 공통 T포즈를 별개 전투 동작으로 세지 않는다. 상품 설명의 120+/130+ 전체판 수량과 무료 저장본 수량을 혼동하지 않는다.
- A 기본 채택: 해당 동작의 베이스로 선정. 배필과 동일한 움직임 또는 지금 바로 완성된 게임 표현을 뜻하지 않는다.
- B 조건부 후보: 용도에 맞지만 무기/접지/접점/상태 전환 보정 후 활용.
- C 보유 적합 클립 없음: 이번 보유 라이브러리로 충족하지 못함. 다른 출처 탐색 필요.
- D 이번 보병 세트 제외: 현재 목표에 맞지 않아 보관. 삭제 대상이라는 뜻이 아니다. P 임시 표현, R 리그 참조는 별도 표시한다.
- 전체 86항목을 분류했다. 추가 후보와 비교용 27클립은 10/35/60/85% 시점 총108자세를 현재 Armature에 리타깃해 확인했다. 나머지 기본 모션은 기존 적용 검증 기록을 이용했다. 제외 클립까지 전부 프레임별 시각 심사했다는 뜻은 아니다.

## 우선 활용 순서

1. 기본 이동: 기존 Idle/Walk/Sprint 유지, Jog를 중간 달리기 후보로 추가 선정. 움직임 자체의 속도·가속·보폭은 다음 구현에서 맞춘다. 현재 사용자 이동 속도 8 / Sprint 12는 바꾸지 않았다.
2. 권총: Aim 3점/Shoot/Reload 유지. Pistol_Idle_Loop는 양손을 든 대기로만 검토. 배필처럼 보이는 손 그립·탄창 접점·1인칭 무기 위치를 별도로 맞춘다.
3. 근접: 직선 Jab/Cross 유지. Hook/Hook_Rec은 선택적 추가 공격. 훅을 정면 주먹의 교체안으로 사용하지 않는다. 현재 총 근접 PunchCross와 파생 가드는 완성 전용 에셋이 아니다.
4. 신규 표현 후보: Hit_Chest/Hit_Head → OverhandThrow → Roll. 이 순서는 포트폴리오 개발 제안이며 이번에는 코드/재생 이벤트를 추가하지 않았다.
5. 부족 에셋 우선순위: 군인 포복 세트 → 장총 전투 세트/1인칭 팔 → 전용 총 근접 → 소생/끌기 → 차량별 승하차. 소생·차량은 서로 맞물리는 접점과 상대/좌석별 포즈가 필요하다.

## 변경 전 비교·변경 보고·검증

이전 적용/전체 수집 작업의 파일 manifest를 기준으로 현재 파일을 비교했다. 시작 시 이전 수집 작업 이후 관련 파일 변화는 없었다. 이번 시작 시점에 새로 저장한 baseline과 종료 시점도 일치한다. 기존의 다수 미커밋 변경은 보존했다. 과거 작업 전체의 사용자 변경 이력을 Git HEAD 비교만으로 구분했다고 주장하지 않는다.

신규 파일은 이 폴더의 선정 문서1개, CSV2개, 후보 이미지4개, 파일 manifest1개다. 스크립트·메서드·필드·직렬화 값·컴포넌트·참조·에셋 삭제/교체는 없다. 런타임 동작의 전후 차이는 없다. 목적은 사용할 소스와 부족한 모션을 명시하는 것이다. 문서/목록은 런타임에서 분리하여 저장했다. 새 클래스/상속/인터페이스를 도입하지 않아 OOP/SOLID 코드 예외는 없다.

검증: 전체86항목 중복/개수 확인, 모든 선택 경로 존재 확인, 원본/기존 변경 파일 baseline 해시 보존, 격리 Unity 27클립108시점 렌더 배치 종료 코드0 및 캡처 결과 시각 확인. 초기 미리보기의 스킨 캐시 문제는 메시 고정 방식으로 바로잡았다. 게임 변경이 없으므로 PlayMode 전체 테스트는 새로 실행하지 않았다. 실제 연결 시 Unity Editor에서 손·무기·탄창 접점, 상체 마스크, 지형 접지, 시작/취소/복귀, 1·3인칭 화면 품질과 타격/발사 이벤트를 확인해야 한다.
